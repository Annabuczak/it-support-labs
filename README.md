# IT Support Labs

Practical Windows, networking, and IT support troubleshooting labs.

## Repository sections

- [Windows Networking](windows-networking/) — networking configuration, connectivity, and diagnostics.
- [Troubleshooting Tickets](troubleshooting-tickets/) — documented symptoms, diagnostic steps, resolutions, and lessons learned.

This repository documents practical IT support work in a clear, repeatable format for learning and portfolio use.
