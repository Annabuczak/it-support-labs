# IT Support Labs

Practical Windows, networking, and IT support troubleshooting labs.

## Repository sections

### Core support

- [Troubleshooting Tickets](troubleshooting-tickets/) — documented symptoms, diagnostic steps, resolutions, and lessons learned.
- [Hardware and Peripherals](hardware-and-peripherals/) — desktops, laptops, printers, displays, storage, and peripheral diagnostics.
- [Microsoft 365 and Email](microsoft-365-and-email/) — Outlook, Teams, OneDrive, account access, and email support.
- [Windows Administration](windows-administration/) — system configuration, maintenance, and support procedures.

### Infrastructure and technical labs

- [Windows Networking](windows-networking/) — networking configuration, connectivity, and diagnostics.
- [Active Directory](active-directory/) — users, groups, permissions, policies, and support tasks.
- [PowerShell Automation](powershell-automation/) — reusable scripts for Windows administration and support tasks.
- [Virtualisation and Homelab](virtualisation-and-homelab/) — virtual machines, test environments, and infrastructure practice.

## Purpose

This repository documents practical IT support work in a clear, repeatable format for learning and portfolio use.
