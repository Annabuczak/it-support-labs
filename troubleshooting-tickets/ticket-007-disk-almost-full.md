# Ticket 007 – Disk Almost Full

**Category:** Storage / Performance  
**Environment:** Windows 11 VM  
**Status:** Resolved

## Issue
The computer had very little free storage space remaining.

## Investigation
I checked the C: drive through **File Explorer → This PC**.

I then opened **Settings → System → Storage** and reviewed the main storage categories, including installed applications, temporary files, system files and other data.

## Resolution
I identified safe cleanup options using Windows Storage settings rather than manually deleting unknown system files.

## Verification
Available disk space was checked again after the investigation and cleanup.

## What I Learned
Low disk space can contribute to performance and update problems. Storage should be investigated systematically rather than deleting files from Windows system folders without understanding their purpose.
