# Ticket 006 – Computer Extremely Slow

**Category:** Performance  
**Environment:** Windows 11 VM  
**Status:** Resolved

## Issue
User reported that their computer was running extremely slowly.

## Investigation
I opened Task Manager and checked:

- CPU
- Memory
- Disk
- Network

I sorted the process list by each resource to identify processes using unusually high amounts of system resources.

## Resolution
The system's resource usage and running processes were analysed to identify possible performance bottlenecks.

## Verification
I confirmed that there was no unexplained excessive resource usage after troubleshooting.

## What I Learned
Task Manager provides a quick way to determine whether poor performance is related to CPU, RAM, disk activity or a particular application before moving to more advanced troubleshooting.
